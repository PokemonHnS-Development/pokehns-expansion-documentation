How to patch

Important:

  • The ROM must match the SHA-1 hash F3AE088181BF583E55DAF962A92BB46F4F1D07B7.
  • Do not use a zip file for the Pokémon Emerald ROM.
  • Pre-2.0 saves are not compatible with 2.0+.
  • Do not trust other websites that claim to host “official” patched ROMs or base files.
  • If you encounter issues, check the documentation and bug-report channels in the official Discord.
Hackdex (Recommended)
  1. Go to the official Pokémon Heart & Soul Hackdex page.
  2. Select Choose Pokémon Emerald ROM and upload a legal copy of Pokémon Emerald Version (U).gba.
  3. Select Agree and Patch.
  4. The patcher will automatically download a patched file named Pokémon Heart and Soul (v2.0.6).gba. Use that file to play.
GitHub and ROM Patcher JS

To patch the game from GitHub, you need a legal copy of Pokémon Emerald Version (U) in .gba format, the matching .ups patch file from the latest release, and a ROM patcher such as Rom Patcher JS.

  1. Download the official .ups patch from the GitHub releases page. The file will end in .ups.
  2. Upload a legal copy of Pokémon Emerald Version (U).gba.
  3. Open Rom Patcher JS. Upload the Pokémon Emerald .gba file into the ROM file section and the Heart & Soul .ups patch into the Patch file section. Wait for the green checkmark, then click Apply Patch.
  4. The patcher will automatically download a patched Heart & Soul GBA ROM (typically named the same as your uploaded Emerald Rom; we highly recommend renaming it to Pokémon Heart and Soul.gba or similar). Use that file to play.
