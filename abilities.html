Settings that change how abilities work

Chosen when you start a new game, in the challenge menu. The rest of this page describes each ability's default behaviour.

  • SYNCHRONIZEOriginal: SYNCHRONIZE works as in GEN III. 50% chance to copy nature.Modern: SYNCHRONIZE works as in GEN VIII+. 100% chance to copy nature.
  • STURDYOriginal: STURDY works as in GEN III. Only negates OHKO moves (GUILLOTINE, etc.)Modern: STURDY works as in GEN V+. {PKMN} survive lethal hits with 1HP.
  • LEGEN. ABILITIESOriginal: PRESSURE stays as the main ability of some legendaries.Modern: Legendaries have PRESSURE changed for a better ability.
